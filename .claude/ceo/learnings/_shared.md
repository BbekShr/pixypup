# Shared lessons (every agent)

## Active
- Resolve every `.claude/...` path against the repo root in your brief, never against your home directory.
- Never `git stash`, `checkout`, `switch`, `reset` or `rebase`: other agents share this tree.
- Every finding needs a failure scenario (input/state → wrong outcome) with file:line.
- Tests never call the real Meta API: inject `fetchImpl` into `MetaClient`. A live check needs `MODEL_API_KEY` and is reported with call count and timing only.
- Prove overlay and main-process changes in a real launch over CDP (`/pixypup-verify`); `screencapture` doesn't work from agent shells.
- Contracts change in pairs: `contracts/*.schema.json` and `contracts/types.ts` in the same commit.
- Match window titles with anchored, product-specific patterns, never bare keywords: titles carry user paths and filenames (B1, `src/screen/decide.ts`).
- Validating a policy file: a dropped invalid key is a failure, not a no-op. Never decide "missing" with `existsSync` (false on EACCES); read and treat only ENOENT as missing (B2/B3, `src/main/settings.ts`).
- Fail-closed tests need an fs mock that can throw ENOENT and EACCES, or they only prove what the mock can express (B2/B3).
- Muse Spark: use `strict: true` schemas (strict:false garbled keys live); with web_search on, extract the last JSON object from narrated text; JSON output carries no url_citation annotations, so ground sources against web_search_call results (F18).
- Side tasks that must not outlive a pipeline share one AbortController aborted in a catch around the main stage; bound how long the main result waits for them (F18).
- Prefs that mirror OS settings (login item) write to the OS only on the explicit user action, never from a general sync (F16).
- The admin file is a whitelist of privacy restrictions (`ADMIN_KEYS`); every new setting is user-owned unless deliberately added (F16).
- WAAPI: an `easing` in the options applies to the whole animation; overshoot easings make later keyframes arrive early. Put pop easing on the first keyframe (F17).
- Live end-to-end runs with the real model find what unit tests can't (lost first word, name not boosted): every Meta-integrated feature gets one real-key run through the app path, not just the client (F8).
- Reset per-session handles at the top of start(); attach abort listeners before awaiting a handshake (F8).
- The CSS transform origin is also the `scale(flip)` mirror axis: never move it to pivot; keep it and add a translation (`pivotShift`). A hard clamp that zeroes velocity reads as a wall: soften the dynamics, keep the clamp as a safety stop (F21).
- Click-through (`setIgnoreMouseEvents`) can't be observed over CDP; judge a first-frame jump by translate minus pointer motion, not the raw delta (F21).
- Briefs for editors in a shared tree: commit by explicit path, never `git add -A`; the worktree-isolation hook blocks writes outside the session's own worktree, and `isolation: worktree` agents start from origin/main (cherry-pick their commits) (F25).
- Generated art is approximate: Muse drew ~4 distinct poses for an 8-phase prompt. Measure what the art does (stride from the planted foot) and let procedural motion carry the phases; cap model-driven scales (F28).
- A keyword secret regex needs no leading `\b`: `_` is a word char, so `AWS_SECRET_ACCESS_KEY`/`GITHUB_TOKEN`/`client_secret` slip past `\bsecret`; test redactors on env-style names, JWTs and quoted values (deep 2026-11-01, `src/api/redact.ts`).
- Before any `[^a-z0-9]` keyword filter, `normalize('NFKD')` and drop `\p{Cf}\p{M}`: zero-width chars otherwise become word breaks (NFKC recomposes accents, so use NFKD) (deep 2026-11-01, `src/api/pet-talk.ts` isCrisis).
- An overlay act whose only exit is a specific state (talk 'go' needs `walk`) must be cleared by user commands BEFORE the queue check and when that state is left; a fixed deadline cuts legitimate long walks (deep 2026-11-01, `src/overlay/overlay.ts`).
- A request timeout bounds the request only: clear it when the reply arrives, or local work after it gets aborted under load (deep 2026-11-01, `src/api/pose-pipeline.ts` attempt).
- Tests that loop `expect()` per frame time out under full-suite load: collect violations and assert once (deep 2026-11-01, overload-choreo test).
- UI diffs: green gates and state checks say nothing about clipping. Every touched window gets screenshots the CEO opens, plus an overflow probe that includes overflow:auto containers and visibility (`checkVisibility()`); measure spare as last visible child bottom minus container bottom (deep 2026-11-02: welcome, making and name steps, Talk input all shipped clipped past a GO).
- Long-content cases are part of the check: a voice-prefilled sentence, a long pet name, a full chat log, error copy shown (deep 2026-11-02, Talk input).
- When the UI hides a feature (offline/admin), the IPC handler must enforce the same rule; hiding is not a guard (deep 2026-11-02, obCheckKey).
- A shared fallback that also serves crisis replies must pin crisis to a fixed neutral line (deep 2026-11-02, `src/api/pet-talk.ts` localReply).
- A sprite rotating about its foot drops a paw by d·sinθ: the floor needs that headroom (deep 2026-11-02, sit tilt clipped 5 px).

## Archive
- Before a CDP runtime sample, check `ioreg -l | grep CGSSessionScreenIsLocked` and `document.visibilityState`: a locked Mac hides the overlay, pauses rAF and freezes the pet; report the gate blocked, not failed (walk-quality).
- Don't shrink strideFromFrames' lower clamp by frame count: every pack collapses to the floor and feet skate ~4x body speed; a faster drawn walk is a deliberate foot-slide trade (walk-quality, dropped 94886a5).
- When a PR changes walk or animation behaviour, grep README.md and docs/index.html for wag/rig/baked/model counts and re-copy `assets/pets/*/side_*` into `docs/img` (cmp) before closing: docs went stale within hours of #39.
- A generated bundle committed under `docs/` must be regenerated from the real source (`npm run site-js`), never hand-ported: the site's walk drifted from the app once already (docs-latest).
- After scripting inline JS into `docs/index.html`, extract it and `node --check` it: one redeclaration silently kills the whole page (docs-latest).
- A "never sent" promise covers every later-turn buffer (history, retries), not just the first request: F31 crisis text leaked via chat history on the next turn (`src/main/talk-history.ts`).
- A route that forwards voice transcripts to a second model widens consent: prefill the UI and let the human press Send instead (F31 `prefill`).
- Never `git commit --amend` on a branch another agent shares: it rewrites whatever HEAD is now. Make a new fixup commit (F31).
- Prove a reply came from the model by comparing it with the fixed local fallback, not by sampling sockets (sub-second calls slip past lsof) (F31).
- Before a runtime check, look for another worktree's dev instance on 5173/9333; vite falls through to 5174 by itself, so pick a free CDP port such as 9444 (F31).
- Image work is verified by looking at the real output (render the frames at true scale), not by tests alone: F3's tests passed while live frames showed clipping and a wrong-eared pose.
- Muse Image draws past its canvas edge and drifts on identity: prompts must ask for margins and pin ears/face; reject edge-touching output and retry (F3).
- Import shared validators from a leaf module; importing from `pose-pipeline.ts` pulled sharp into the Electron main bundle (F4).
- Every pointer path (up, cancel, lostpointercapture) restores click-through; test the invariants as pure functions, not formula re-statements (F4).
- Before a verify run, check who owns the debug and renderer ports (the maintainer may be running the app); use a different `--remoteDebuggingPort` and never kill processes you didn't start.
- When separate image calls copy a reference, ask for one sprite sheet and slice locally; save real model output as a test fixture, because synthetic fixtures are too clean (F13: Muse sheet frames nearly touch).
- Async user flows that outlive their window are owned by main with a run token; the window rebuilds from main-held state (F5a `src/main/run-state.ts`).
- Reviewers stay read-only: never `git checkout`/`switch` in the shared tree, even detached (F5a reviewer slip).
- A multi-phase sequence that owns the pet gates every input (menu, pointer) on a pure busy(phase) predicate and queues the last command (F5b `src/overlay/handoff.ts`).
- Reduced motion: never `animation-duration:1ms` on infinite animations without `animation-iteration-count:1` (strobe); WAAPI loops need their own check.
