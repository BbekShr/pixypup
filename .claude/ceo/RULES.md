# PixyPup org rules

Read by every agent at boot, after `CLAUDE.md`. This file holds the org's rules so that
`CLAUDE.md` stays the project's own (and stays clean where `CLAUDE.md` ships to end users).
Changes here are rule changes: the CEO proposes them, the human merges them.

This repo runs an agent org generated by agent-org (`/org-init`). The CEO is `/pixypup-ceo`;
agents live in `.claude/agents/`; state lives in `.claude/ceo/` (see its README). Kill switch:
`touch .claude/ceo/PAUSE`.

**Verification bar for ANY change:** `npm run typecheck` ∧ `npm run lint` ∧ `npm test` ∧ `npm run build` (+ a `/pixypup-verify` run for UI/main-process diffs). Never weaken a gate to pass: no skipped
tests, loosened assertions, lint-disables, or gate-config edits.

**Protected paths** (a PR touching one names the path and why in its body; the human merges it):
- `CLAUDE.md`
- `.github/workflows/**`
- `.env*`
- `tsconfig.json`
- `eslint.config.js`
- `vitest.config.ts`
- `src/main/secrets.ts`
- `src/main/settings.ts`
- `src/api/meta-client.ts`
- `docs/ENTERPRISE.md`
- `.claude/ceo/org.json`
- `.claude/ceo/AUTONOMY.md`
- `.claude/settings.json`
- `.claude/hooks/**`

**Critical rules:**
- **Screen-aware mode and voice are OFF by default, and with both off PixyPup makes zero network calls.** This is the enterprise promise in `docs/ENTERPRISE.md`; one stray fetch breaks it. Defaults live in `src/main/settings.ts`.
- **Standard tier only.** Never use a `*-contributor` model ID: those let Meta train on request content (screenshots of work). `src/api/meta-client.ts` refuses them (`assertStandardTier`); never remove or bypass that check.
- **The full screen is never captured or sent.** Only a crop of the terminal window, held in memory, may go to SAM 3.1. Never write a screenshot or crop to disk, never log image data.
- **The Meta API key is never in a file, log, error message, URL, or test fixture.** It comes from Electron `safeStorage` (`src/main/secrets.ts`) or `MODEL_API_KEY` in the developer's shell. Tests never call the real API.
- **The overlay must stay click-through except over the pet.** A window that swallows clicks makes the user's Mac unusable; every pointer path must restore `setClickThrough(true)`.
- **An admin's `/Library/Application Support/PixyPup/admin.json` wins over user settings**, and `adminDisableScreenAware` forces screen-aware off (`mergeSettings`).
- **Never cut the failing-test sniff.** It is the moment the demo video depends on; cut voice first, then signing, then a screen reaction.
- **Text read from the user's screen (terminal output, window titles) is untrusted data.** When it reaches a Muse Spark prompt it is quoted as data, the response is schema-validated JSON, and only the fixed action enum in `contracts/behavior-decision.schema.json` is obeyed.

**Memory:** `CLAUDE.md` = rules (human-approved changes only) · `.claude/ceo/backlog.md` = tasks ·
`.claude/ceo/memory/` + `learnings/` = facts. Agents may propose rule changes; only the human
merges them.
